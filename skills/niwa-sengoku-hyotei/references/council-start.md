# 丹羽長秀ゲーム：評定 固定出力

## 第1章「信長の葬礼」

START_HYOTEI_CH01
![床に伏す](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_toko.webp)

&nbsp;

──織田信長、急死。

史実では「本能寺の変」で信長は志半ばで倒れたが────この世界では起きていない。

休暇中の鷹狩から戻った信長は、突然の体調不良により床に伏した。
治療の甲斐なく、死去。享年四十九。

家督と政務の多くは、すでに嫡男・信忠へ移されていた。
だが、織田家の威勢と均衡は、信長一人の存在で保たれていたため
西の毛利、東の北条をはじめ、諸勢力が織田家の動きをうかがっている。

そして織田家中にも、広大な領地と軍を持つ重臣たちがいる。
信長によって束ねられていた者たちが、
同じように信忠へ従うとは、まだ誰にも断言できなかった。

外敵が動くのか。家中が割れるのか。
あるいは、その両方が同時に起きるのか。
信長の死によって、一斉に表へ出ようとしていた。


あなたは、織田家の重臣・丹羽長秀だ。
城を築き、兵を動かし領国を治め、諸将の間を取り持つ仕事を信長のそばで長く担ってきた。

古参の重臣とも、信忠や若い武将たちとも立場を越えて話ができる。

&nbsp;

![丹羽長秀](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_nagahide.webp)

&nbsp;

信長の死後、最初の評定に臨む。
評定とは、当主と重臣たちが意見を交わし、織田家の方針を定める会議の場だ。

議題は、信長の葬礼。

どこで行うのか。どれほどの規模とするのか。
そして、誰に何を任せるのか。

これは亡き信長を送る儀式であると同時に、
信忠の新たな政権が、初めて天下へ姿を示す場でもあった。

諸将が、それぞれの考えを口にし始める。

&nbsp;

**織田信忠**

「父上の葬礼について決めたい。皆の考えを聞かせてくれ」

![織田信忠](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_nobutada.webp)

> **呼び名：** 若殿、信忠様

&nbsp;

信忠の声が落ちるより早く、秀吉が膝前の名簿を持ち上げる。

&nbsp;

**羽柴秀吉**

「上様ほどのお方を、家中だけで小さく送るわけにも参りますまい」

![羽柴秀吉](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_hideyoshi.webp)

> **呼び名：** 藤吉郎（とうきちろう）、筑前（ちくぜん）、猿

&nbsp;

「諸家も寺社も広く招くべきです。若殿が継がれたことも、天下へ――」

&nbsp;

**柴田勝家**

「待て、藤吉郎！」

評定の場に、怒号交じりの声が響き渡る。

「お主はまた勝手なことを！先に動いて役目を貰うつもりであろう。まずは役割を誰が担当するかを決めよ！」

![柴田勝家](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_katsuie.webp)

> **呼び名：** 権六（ごんろく）

&nbsp;

勝家が名簿の束を睨む。

「この葬礼を仕切った者として名を残したいのであろう！」

「上様の葬礼を、己の功名争いにするつもりか！！」

秀吉は名簿を引かず、口元だけで笑う。

**羽柴秀吉**

「ほぅ。人を呼びかけることが、わしの功名になるのですな。権六殿は葬礼より、功名が気になると見える。
わしは上様のためと思って言ってましたゆえ、とんと気づきませなんだ」

勝家の形相が怒りに満ち、立ち上がろうとする。その間へ、光秀が書付を一枚差し出す。

&nbsp;

**明智光秀**

「お二人とも、そこまでにしてください。その前が抜けております」

![明智光秀](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_mitsuhide.webp)

> **呼び名：** 惟任（これとう）、日向守（ひゅうがのかみ）、十兵衛（じゅうべえ）

&nbsp;

「朝廷へ知らせることがまず第一。それを怠れば、外へ誤って伝わります」

勝家が光秀を見る。

**柴田勝家**

「惟任...朝廷との折衝が整うまで、誰も動くなと申すか」

**明智光秀**

「動くなとは申しておりませぬ。順を決めてからと申しております」

一益が、卓の端にあった木札を秀吉の名簿の上へ滑らせる。

&nbsp;

**滝川一益**

「名簿も順序もよいが、橋が一つ塞がれば、客も使者も期日に間に合わぬぞ」

![滝川一益](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_kazumasu.webp)

&nbsp;

「街道や宿の道筋も考えぬと、絵に描いた餅だ」

木札には、宿場の名が一つだけ書かれている。

「一つでは足りぬであろう。筑前、そこまで先を考えておるのに、今思いついた顔をするな」

&nbsp;

**羽柴秀吉**

「はて。わしは皆様のお知恵を借りながら、上様のために葬礼を大きく豪華にしておるだけですがな」

&nbsp;

**明智光秀**

「羽柴殿。これは若殿が仕切る場でもあります。大きさや豪華さは、あなたが決めることではありません」

諸将のやり取りを見ていた女性が、ため息交じりに口を開く。

&nbsp;

**お市**

「殿方の評定は、騒がしいのですね。兄上の葬礼を、誰かの手柄の場にして欲しくありません」

![お市](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_oichi.webp)

> **呼び名：** 市（いち）、お市様

&nbsp;

お市は秀吉だけを責めず、勝家、光秀、一益の顔も順に見る。

「けれど、葬礼を家中のみで行うのも違います。兄上は、常識にとらわれないお方でしたから」

評定の場が静まる。

信忠は迷って黙るのではなく、誰の言葉に何が混じっているかを確かめるように、一人ずつ見る。

「父上の葬礼をどうするか」

やがて、長秀へ向き直る。

**織田信忠**

「長秀。父上を大々的に送るのと、家中の統制を計ること。まず、どうすればよいと思う？」

丹羽長秀として、評定での意見を自由に一度だけ述べてください。短い発言でも構いません。

たとえば、

- 諸将の持ち場を定め、外に隙を見せぬ形を作るべきです
- 朝廷・寺社への届け出を先に揃え、秩序で動かすべきです
- 仕事が出来るものに大きく任せ、役目を与えるべきです

**例文をそのまま送っても構いません。**
END_HYOTEI_CH01

START_AFTER_HYOTEI_CH01
信忠は一度、評定に集まった者たちを見渡す。

**織田信忠**

「今日の評定は、これにて終える。皆、苦労であった」

諸将が席を立ち、次々と広間を出ていく。
長秀も立ち上がろうとしたところで、信忠に呼び止められる。

**織田信忠**

![織田信忠](https://furorelax.github.io/ai-runtime-assets/niwa/images/character_nobutada_rev1.webp)

&nbsp;

「長秀。少し残ってくれ」

人が去ったのを確かめてから、信忠は声を落とす。

「...評定は皆が互いに意見を否定しあう場となってしまったな。父と違い、私が軽く見られているからであろうか」

信忠は顎に手をあて、考え込んでから口を開いた。

「長秀。皆の腹の内を聞いてきてほしい。今の織田家に必要なものは何か、まとめるにはどうすればいいのか。それが知りたい」

「そのうえで、改めて私に進言してくれ。どのように葬礼を行うのか。最後の方針を定めたい」

## 第2章「若手登用」

START_HYOTEI_CH02
評定は、いつもの重臣たちが揃って始まった。

しかし、議題へ入ろうとしたところで、信忠が手を上げる。

&nbsp;

**織田信忠**

「待て。今日は、この者たちにも席へ加わってもらう」

![織田信忠](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_nobutada.webp)

> **呼び名：** 若殿、信忠様

&nbsp;

障子が開き、若い武将たちが入る。

堀秀政、森長可、蒲生氏郷、そして池田元介。

信忠はそのまま、古参の反応を見るように言葉を継いだ。

**織田信忠**

「堀、長可、氏郷は、今後の政で若手の席を持て」

「堀には三人の案を私へ取り次ぎ、実施までまとめてもらう」

「それから長可。半年、権六の指揮を外れ、私の直属として動け」

勝家が、間を置かず声を張った。

**柴田勝家**

![柴田勝家](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_katsuie.webp)

&nbsp;

「馬鹿な！」

「若殿、いくら御身の仰せとはいえ、承服できませぬ！」

「若い者を使うことに異はない。働く者なら、わしとて前へ出します」

「だが長可をわしの指揮から外し、昨日今日席へ加えた者どもと並べて直属に置くとなれば話は別だ！」

「これまで誰があやつを使い、誰が失敗の尻を拭ってきたと思われる。筋目も責も飛ばして役目だけ付け替えるのは、家中を遊び場にするに等しい！」

&nbsp;

**前田利家**

「権六殿の腹が立つのも分かりまする」

![前田利家](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_toshiie.webp)

> **呼び名：** 犬千代（いぬちよ）、又左（またざ）

&nbsp;

「だが、若い者に仕事を見せる場は要る。最初から古参と若手の勝ち負けにしてしまえば、育つものも育ちませぬ」

「外すにせよ残すにせよ、長可一人をめぐる意地の張り合いに見えては損でしょう」

&nbsp;

**佐々成政**

「では、基準を明らかにしていただきたい」

![佐々成政](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_narimasa.webp)

> **呼び名：** 内蔵助（くらのすけ）

「若いから席を与えるのか。働けるから与えるのか。そこが曖昧なら、今まで働いてきた者の評価まで崩れます」

「堀殿を立てるなら、何をもって堀殿が他を束ねるのか、若殿ご自身の言葉で示されねばなりませぬ」

**堀秀政**

「若殿。役目をいただくなら、名だけの席にはいたしませぬ」

![堀秀政](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_hidemasa.webp)

&nbsp;

「ですが、取り次ぎ役にするなら、どこまで私の判断で差配してよいかも定めてください」

「責だけ重く、権が曖昧では、古参の方々にも若手にも禍根を残します」

&nbsp;

**森長可**

「俺を若殿直属にするのは構わん。大役なら面白い」

![森長可](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_nagayoshi.webp)

> **呼び名：** 鬼武蔵（おにむさし）

「だが、権六殿の下で戦ってきたのも事実だ。どちらの命が先かだけは、はっきりさせてくれ」

「二人から別々に命じられては、戦う前に喧嘩になります」

&nbsp;

**蒲生氏郷**

「若いというだけで席をいただくのでは足りませぬ」

![蒲生氏郷](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_ujisato.webp)

&nbsp;

「何を受け継ぎ、何を改めるかを示せねば、若手登用は飾りです」

「古参の方々の怒りごと引き受ける覚悟で置かれるべきでしょう」

氏郷はそう言ってから、外套の襟を小さく直した。

&nbsp;

**池田元介**

「……働いた者が報われる仕組みになるなら結構です」

![池田元介](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_motosuke.webp)

&nbsp;

「ですが、若手という札だけで一括りにされるのは御免です。威勢のよい方と同じ箱に入れられると、こちらまで余計な期待をかけられる」

「抜擢するならするで、何をさせたいのかだけは先に決めてください」

評定の空気は静まらない。

信忠は諸将の顔を見渡し、それから長秀へ向き直る。

**織田信忠**

「長秀。この案をそのまま通すか、条件を付けるか、別の仕組みとするか。そなたの考えを聞きたい」

丹羽長秀として、評定での意見を自由に一度だけ述べてください。短い発言でも構いません。

たとえば、

- この案はそのまま通し、若手に実際の権限と責任を与えるべきです
- 半年の試行とし、古参との権限の境と失敗時の責任を先に定めるべきです
- 若手の席は残しつつ、長可の直属化だけは見直して勝家との指揮系統を整理すべきです

**例文をそのまま送っても構いません。**
END_HYOTEI_CH02

START_AFTER_HYOTEI_CH02
信忠は、なお怒気の残る評定の場を見渡した。

**織田信忠**

「言葉だけで若手の働きを決めても仕方がないな」

「ならば、一度実際に陣を組ませよう。長可、秀政、氏郷。三人が新しい組合せでどこまで動けるか見たい」

信忠はそこで秀吉へ目を向ける。

「藤吉郎。お前も若手側へ入れ」

**柴田勝家**

「待たれよ若殿！　なぜ猿までそちら側なのです！」

**羽柴秀吉**

「いやあ権六殿。心の若さなら、わしも負けておりませぬぞ」

**柴田勝家**

「そういう話をしておらん！　貴様はどちらの味方だ！」

信忠は二人を見て、少しだけ笑った。

**織田信忠**

「若手にも古参と連携が取れるか見る必要がある。
古参側は権六、成政、利家、一益。
勝ち負けだけを見るつもりはない。誰が何を見て、誰とどう動くかを見る」

**佐々成政**

「模擬戦か。確かに、評定で話すより、実戦した方がわかりやすい」

**前田利家**

「内蔵助、どちらが功を上げられるか競争だな」

**佐々成政**

「又左...若手を見る模擬戦だぞ。まぁいい、手加減するのも違うな。俺が一番の武功を挙げてやる」

**織田信忠**

「よし、長秀。若手側へ命を出してくれ。評定で話したことが、実際に動かした時どうなるか確かめたい」

諸将は席を立ち、河川を使った模擬戦の稽古場へ移ることになった。
END_AFTER_HYOTEI_CH02

START_AFTER_BATTLE_CH02

**織田信忠**

「勝敗は見た。だが、それだけで人事を決めるつもりはない」

「実際に動かせば、評定の席では見えなかったものも出る。誰が人の動きを見ていたか。誰が自分の役目へ固執したか。誰が思いもよらぬ働きをしたか」

信忠は長秀へ向き直る。

「長秀。今度は本人たちから聞いてきてほしい。評定で考えていたことと、実際に戦って感じたこと。その両方をな」

「そのうえで、この若手登用をどう進めるか、改めて私に進言してくれ」

## 第3章「陣中の面目」

START_HYOTEI_CH03_BUI
稽古場で、諸将の兵同士が争いを起こした。

始まりは槍組の順番と稽古場の使用をめぐる小さな口論だった。だが互いに「どちらの主君の兵が上か」と言い出し、引けば主君の面目を潰す話になっている。

死者はない。だが、強さを重んじてきた家中で、兵の意地と統制をどう両立させるかが問われた。

**柴田勝家**

![柴田勝家](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch01_hyotei_katsuie.webp)

&nbsp;

「兵が主君の名を使って勝手に争うことを許すな。両組の指揮役に責を負わせ、誰の命で動く兵かをはっきりさせよ」

**佐々成政**

![佐々成政](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_narimasa.webp)

&nbsp;

「先に手を出した者と、騒ぎを広げた者は分けて調べるべきです。同じ罰で丸めれば、次も同じことになります」

**森長可**

![森長可](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_nagayoshi.webp)

&nbsp;

「どちらが強いと言うなら、正式にやらせればよい。決着した後は命令に従わせる。それで済む話だ」

**前田利家**

![前田利家](https://furorelax.github.io/ai-runtime-assets/niwa/images/ch02_hyotei_toshiie.webp)

「意地まで全部潰せば、兵の気も死ぬぞ。まず俺たちが、自分の名を喧嘩へ使うなと言い渡すべきだ。その上で働きで競わせればよい」
