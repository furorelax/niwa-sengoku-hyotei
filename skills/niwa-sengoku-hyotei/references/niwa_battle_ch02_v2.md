# 1. 模擬戦の意味

評定で若手登用を巡る意見が割れた後、信忠は「若手に席を与えるなら、実際に組ませて動きを見る」と決める。

目的は「若手が古参より強い」と証明することではない。

- 若手三人が新しい組合せで実際に動けるか
- 堀が状況を整理できるか
- 長可の突破力を命令の中へ置けるか
- 氏郷が好機を広げられるか
- 古参側が何を強みとしているか
- 秀吉を若手側へ置いた時、戦場をどう変えるか

を見るための模擬戦。

勝敗と内容は、第2章後半の個人会話・進言・章帰結の材料にする。

# 4. 第2章マップ固有の山ルール

山上のユニットは、有利な陣地を得る。

- 山上ユニットが攻撃を受けた時、通常は戦果を1段階軽減
- `堅牢`等の別の1段階軽減と重複して2段階軽減にはしない
- `精密`で山上ユニットを攻撃する場合、この山による軽減を無視し、戦果も大きくなりやすい
- 山そのものは射線遮断地形。山の向こう側へは射撃不可
- 山上の対象そのものを射撃することは可能

# 5. 第2章固有の策

## 【策：仮渡河】

使用者：羽柴秀吉

使用回数：この模擬戦で1回

移動後にも使用可能。

秀吉の現在位置からマンハッタン距離1〜2以内にある、**空いている川マス1つ**を対象にする。

対象を、

`river / passable=false`

から、

`temporary_crossing / passable=true`

へ変更し、盤面では`🟫`と表示する。

人足を回して浅瀬・仮橋を整えた扱いであり、秀吉自身が対象マスへ隣接している必要はない。

策を使用した手番は通常攻撃を行わず終了する。

占有中のマス、既存橋、川以外の地形は対象にできない。

ユーザーが「策を使う」など対象を指定しなかった場合は、現在盤面から最も有効な合法川マスを秀吉が選ぶ。再入力は求めない。

# 7. 勝敗条件

## 若手側勝利

次のいずれか。

- 柴田勝家が戦闘不能
- 古参側4隊のうち3隊が戦闘不能
- 上記へほぼ到達し、古参側が模擬戦続行の意味を失ったと合理的に判断できる

## 若手側敗北

次のいずれか。

- 若手側4隊のうち3隊が戦闘不能
- 若手側が戦線を維持できず、信忠または古参側が続行不要と合理的に判断できる

模擬戦なので死亡・討死は発生しない。

勝敗だけで第2章の人事方針を自動確定しない。

# 8. 敵AIの基本傾向

固定手順ではない。現在盤面から合法手だけを選ぶ。

- 勝家：橋と中央を簡単に明けず、若手の正面突破を受け止める。必要なら前へ出る
- 成政：山の優位と射程を活かし、突出した相手や戦果を出しやすい相手を狙う
- 利家：味方へ寄り、`助勢`を成立させやすい位置を好む。ただし無意味な密集はしない
- 一益：橋正面へ固執せず、秀吉の仮渡河や東西の空きを見て機動する

性格はKnowledgeの人物設定を使うが、合法手を破って性格を表現しない。

# 10. 合戦終了時に残す第2章要約

共通要約に加え、次を見られるようにする。

- 若手三人が互いをどう使ったか
- 秀吉の仮渡河を使ったか、使ったならどこへ作ったか
- 勝家と長可が直接ぶつかったか
- 堀が山上の敵を`精密`で崩したか
- 氏郷が`追撃`を成立させたか
- 利家が`助勢`を成立させたか
- 成政が山・鉄砲をどう使ったか
- 一益がどの経路から圧をかけたか

個人会話では、この実際の出来事を人物ごとの関心へ変換して使う。起きなかった出来事を起きたものとして話さない。
